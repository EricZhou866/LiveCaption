Local Live Captions

Captions are generated on your computer with a local Whisper model. Audio never leaves the browser unless you deliberately configure a remote endpoint below.

Site access

Firefox asks you to grant site access explicitly. Without it the add-on cannot read audio from pages.

Behaviour

Read the log at about:debugging → This Firefox → Local Live Captions → Inspect.

Speech engine

Whisper processes a 30-second window for every update, so "smoothest" keeps a CPU core busy for as long as audio plays — that is what makes Firefox warn that an extension is slowing it down. Partial updates are skipped anyway while the tab is in the background; complete lines are never skipped.

Translation needs a multilingual model (one without the .en suffix).

Audio is uploaded as 16 kHz WAV to this endpoint, in the same multipart format as POST /v1/audio/transcriptions. A local whisper.cpp server works too.

Appearance

Counted from the last caption, once the audio has stopped. Drag the bottom-right corner of the panel to resize it; the size is remembered.

Timing

Lower sensitivity values pick up quieter speech but also more background noise.

Diagnostics

Open the tab you want captions on, come back here and run this. It reports whether the content script reached that tab, what media it found, and how the speech engine is doing.
