Local Live Captions

Captions are generated on your computer with a local Whisper model. Audio never leaves the browser unless you deliberately configure a remote endpoint below.

Site access

Firefox asks you to grant site access explicitly. Without it the add-on cannot read audio from pages.

Behaviour

Many radio players load their stream without asking for CORS, which leaves the browser handing us silence. When that happens this fetches the same stream again, with CORS, purely to read it — it is never played back, but it does use the bandwidth twice.

Read the log at about:debugging → This Firefox → Local Live Captions → Inspect.

Transcript

Off by default. When on, the caption lines of each tab are kept in memory — never on disk, never sent anywhere — until you click Save transcript in the toolbar popup or on the caption panel, which writes a .txt file to your Downloads folder. A tab's transcript is discarded when you close it or load another page, and all of them are discarded as soon as you switch this off. Firefox will ask once for permission to save files.

Speech engine

moonshine-tiny · int8 · CPU (WebAssembly) · Balanced — the fastest combination that works on every machine: about 0.3 s per caption update, from a 27 MB one-time download.

On WebGPU the precision above is chosen for you (a full-precision encoder and a 4-bit decoder), because the GPU backend cannot run 8-bit models. If WebGPU is missing in your Firefox or stalls on a model, captions carry on on the CPU and the panel says so; changing any engine setting gives WebGPU another try.

Whisper processes a 30-second window for every update, so "smoothest" keeps a CPU core busy for as long as audio plays — that is what makes Firefox warn that an extension is slowing it down. Partial updates are skipped anyway while the tab is in the background; complete lines are never skipped.

Whisper encodes a fixed 30-second window for every update, so a short phrase costs it as much as a long one; Moonshine's cost follows the length of the audio, which is why it is the default. Translation needs a multilingual Whisper model (one without the .en suffix).

Audio is uploaded as 16 kHz WAV to this endpoint, in the same multipart format as POST /v1/audio/transcriptions. A local whisper.cpp server works too.

Appearance

Counted from the last caption, once the audio has stopped. Drag the bottom-right corner of the panel to resize it; the size is remembered.

Timing

Lower sensitivity values pick up quieter speech but also more background noise.

Diagnostics

Open the tab you want captions on, come back here and run this. It reports whether the content script reached that tab, what media it found, and how the speech engine is doing.
