Local Live Captions 会在正在播放的标签页上叠加一个字幕面板，就像 Chrome 的 Live Caption 那样——区别是语音识别完全在你自己的电脑上、在 Firefox 内部完成。

• 标签页一开始出声，字幕自动出现
• 全部本地：模型一次性下载 27 MB 之后即可离线使用，音频从不上传
• 支持普通的视频、音频播放器，用 Web Audio 播放的网站，以及其他捕获方式只能听到静音的电台、新闻播放器
• 占用 CPU 少：默认的 Moonshine 模型约三分之一秒就能刷新一次字幕
• 面板可拖动、可缩放、可调字号，深浅两种配色
• 可选（默认关闭）：保留每个标签页的字幕记录，并保存为文本文件
• 需要其他语言时可用 Whisper 模型，也能翻译成英文；支持 WebGPU 的 Firefox 可以开启 WebGPU
• 麦克风输入可用于通话或 Firefox 抓不到音频的场合；也可以改用你自己的 OpenAI 兼容转写服务
• 「Use recommended settings」一键恢复最快、最稳定的设置

快捷键：Ctrl+Shift+L（macOS 为 Cmd+Shift+L）开关当前标签页的字幕。

Firefox 会要求你授予站点访问权限后，插件才能读取页面音频。

已知限制：DRM 加密的视频无法捕获；服务器拒绝跨域访问的音频流也无法捕获（这种情况可以用麦克风模式）；字幕延迟大致等于当前这句话的长度。
